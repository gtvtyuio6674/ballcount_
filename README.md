# 볼카운트 · 간편 배포판

KBO 경기 기록, 포인트 승부예측, 이메일 회원가입, 팬 랭킹, 관리자 화면을 갖춘 개인 야구 사이트입니다.
**코드를 고치거나 GitHub Secrets를 여러 개 등록할 필요 없이 배포하도록 구성했습니다.**

## 시작 방법

1. 이 폴더 **안의 파일 전체**를 본인 GitHub 공개 저장소에 올립니다. ZIP 파일 자체를 올리는 것이 아닙니다.
2. 압축에 있는 **`시작하기.html`을 더블클릭**하고 저장소 주소를 넣어 **내 사이트 배포하기**를 누릅니다.
3. Cloudflare 화면에서 본인 Cloudflare·GitHub 계정을 연결하고 `ADMIN_SETUP_PASSWORD`에 관리자 비밀번호를 정한 뒤 배포합니다.
4. 완성된 사이트의 `/admin`에서 관리자 이메일과 방금 정한 비밀번호를 입력합니다.

비밀번호는 **영문·숫자 포함 12~128자**입니다. Cloudflare의 비밀 입력란에만 입력하고 저장소에 적지 않습니다.
배포 화면에서 새로 만들 운영 저장소의 이름은 예를 들어 `ballcount-live`로 정하면 됩니다.

`시작하기.html` 대신 GitHub **Actions → 볼카운트 배포 시작 → 실행된 항목 → Summary**에서도 본인 저장소용 배포 버튼을 누를 수 있습니다.
Actions의 성공 표시는 **버튼 준비 완료**입니다. 실제 사이트 배포 성공은 Cloudflare 화면에서 확인합니다.

> 서버를 본인 계정에 만들려면 최초 계정 연결은 직접 해야 합니다. GitHub 업로드만으로 외부 계정의 서버를 만들 수는 없습니다.
> 이 배포 버튼 방식은 **공개 소스 저장소**를 사용합니다. 회원 정보·비밀번호·실제 비밀키는 소스 저장소에 들어 있지 않습니다.

## 자동으로 준비되는 것

| 항목 | 처리 방식 |
| --- | --- |
| 웹 서버와 공개 접속 주소 | Cloudflare 배포 |
| 회원·포인트 데이터베이스 | Cloudflare가 생성·연결 |
| DB 테이블 | 배포 스크립트가 마이그레이션 적용 |
| 서버 내부 암호화 키 | 처음 필요할 때 서버가 생성하여 비공개 DB에 보관 |
| 경기 결과·포인트 정산 | 서버 예약 작업이 2분 주기로 처리 |
| 이후 코드 업데이트 | Cloudflare가 만든 운영 저장소에 Push하면 자동 배포 |

계정 ID, D1 ID, Cloudflare API 토큰, 서버 암호화 키를 수동으로 복사해 넣는 과정은 이 간편 배포 흐름에 없습니다.
관리자 비밀번호는 운영자가 정해야 하므로 공통 기본 비밀번호를 넣지 않았습니다.

## 이메일 회원가입 열기

관리자 화면의 **운영 · 이메일 설정**에서 본인의 Resend 발송 키와 인증된 발신 주소를 한 번 저장하면 됩니다.
Resend 계정과 발신 도메인 인증은 운영자의 계정에서 진행해야 합니다. 실제 발송 권한을 파일에 미리 포함할 수는 없습니다.
연결 전에는 가입 화면에 설정 안내가 표시되고, 인증을 생략하는 임시 가입 기능은 제공하지 않습니다.

## 포함된 기능

- 20초 주기 KBO 경기 기록 갱신, 일정·점수·이닝·주자·선발·구장·중계 정보.
- KBO 공식 게임센터와 공식 중계 서비스 연결.
- 경기 전 포인트 승부예측, 확정 결과 정산, 무승부·취소 환불.
- 웰컴 포인트, 매일 출석, 야구 퀴즈, 홈런 챌린지, 배지 상점.
- 이메일 코드 회원가입, 로그인, 일반 회원 비밀번호 재설정.
- 응원팀·프로필·포인트 원장·예측 내역·회원 랭킹.
- 구단 순위와 타자·투수 기록.
- 별도 관리자 로그인, 회원 정지·포인트 조정·환불·공지·보상·배당·메일 설정·운영 기록.
- 모바일·데스크톱 한국어 화면.

영상은 공식 중계 서비스에서 시청하며 자체 재송출은 하지 않습니다.
포인트는 무료 가상 포인트입니다. 입금·구매·현금 환전 기능은 없습니다.

## 기본 포인트

| 항목 | 기본값 |
| --- | --- |
| 가입 | 5,000 P |
| 매일 출석 | 300 P |
| 퀴즈 정답 | 200 P |
| 경기 참여 | 100~5,000 P, 경기당 1회 |
| 마감 | 경기 시작 1분 전 |
| 적중 | 참여금 포함 1.90배, 소수점 버림 |
| 미적중 | 지급 0 P |
| 무승부·취소 | 참여금 반환 |
| 홈런 챌린지 | 참가 100 P, 하루 5회, 결과에 따라 0/100/200/400 P 지급 |

가입·출석·퀴즈·최대 참여금·배당은 관리 화면에서 바꿀 수 있습니다.
KBO 연결이 지연되면 지연 표시와 마지막 기록을 보여주며 새 예측을 막습니다.
정산은 같은 확정 결과를 최소 60초 간격으로 확인한 뒤 처리합니다. 미확정·서스펜디드 경기는 보류합니다.
KBO가 보장하는 개발자 API 계약을 사용하는 구성은 아니므로 응답 변경 시 어댑터 수정이 필요합니다.

## 더 자세한 안내

- [사진 없이 따라 하는 배포 순서](docs/DEPLOY.md)
- [운영·복구·백업](docs/OPERATIONS.md)

개발자용 명령: `pnpm install --frozen-lockfile`, `pnpm db:local`, `pnpm dev`.
로컬 개발 시 `.dev.vars.example`을 `.dev.vars`로 복사하고 개인 테스트 비밀번호를 입력합니다.
Node.js 22.13 이상, pnpm 11.25.0을 사용합니다. React 19·TypeScript·Vinext·Cloudflare Workers/D1 구성입니다.

이번 간편 배포 변경은 파일을 먼저 전달하기 위해 앱 실행·가입·메일 발송·클라우드 배포 테스트를 수행하지 않았습니다.
실제 운영 계정 연결과 메일 발송 권한은 포함되어 있지 않습니다.
